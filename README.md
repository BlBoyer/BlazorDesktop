📘 BlazorDesktop — Desktop Apps with Blazor + .NET

An open-source framework and sample implementation for building desktop applications using Blazor and .NET. BlazorDesktop provides a structured foundation for hosting Blazor UI content inside a native desktop host, enabling developers to write full applications with C#, Razor, and modern .NET tooling without sacrificing performance or architectural clarity.

The project demonstrates:

How to compose a hybrid desktop app with Blazor and a .NET generic host.

A clean application architecture including domain, application, infrastructure, and testing layers.

Example patterns for state management, orchestration, and event-driven coordination.

Whether you’re learning Blazor beyond the browser or building cross-platform desktop tools with .NET, BlazorDesktop offers a practical and extensible starting point.

🛠️ Features

Blazor-based UI powered by .NET desktop host

Sample implementations of data flow, effects, and orchestration

Testing infrastructure to support unit and integration scenarios

Clear separation of concerns across domains and layers

🚀 Getting Started

Clone the repo

Build and explore the layered architecture

Adapt or extend the patterns for your own desktop projects

🧠 Why It Matters

Blazor lets you build rich interactive UIs with C# and Razor instead of JavaScript. BlazorDesktop brings that same productivity and type safety to desktop applications, letting you leverage .NET’s entire ecosystem for desktop scenarios — all without losing the reactive component model you already love from web development.
